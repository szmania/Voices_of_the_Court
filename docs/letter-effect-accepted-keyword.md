# `VOTC:LETTER_EFFECT_ACCEPTED` → Letter Actions Run File Clear

The CK3 mod copies `VOTC:LETTER_EFFECT_ACCEPTED` to the clipboard (via `message_event.363`, defined in `clipboard_codes_l_*.yml`) after it executes `run/votc_letter_actions.txt`. The app recognizes the keyword in both trigger paths (clipboard poll in `ClipboardListener.ts` and the log-tail `TRIGGER_KEYWORDS` set in `main.ts`) and clears the run file via `LetterActionTrigger.clearLetterRunFile()`, mirroring the `VOTC:EFFECT_ACCEPTED` → conversation-run-file pattern. The prior `setTimeout(800)` clear in `LetterActionTrigger.executeLetterAction` is retained as a fallback in case the keyword is slow or absent.\n\n——## Letter Action Prelude Scope Fix\n\n——`ActionEffectWriter.composeLetterScopePrelude` wraps derived `votcce_action_source` and `votcce_action_target` global variable assignments inside a `root = { ... }` block. This prevents CK3 script system errors (`Scoped object is not valid`) caused by running `set_global_variable` at the top level of a console run file without an active character scope context.

Text Generation Connection

Quick Model Connection

Optional low-latency LLM for quick decisions (character targeting, etc.). Uses the text generation connection by default.

Text-generation parameters

The context limit is the maximum number of tokens the model can handle. The application attempts to auto-detect this limit from the API.

You can manually override this by enabling "Overwrite Context Limit" and setting a "Custom Context Limit". If a conversation prompt exceeds the limit, the oldest messages and summaries will be automatically trimmed to fit.
